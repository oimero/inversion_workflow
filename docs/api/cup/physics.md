# cup.physics

物理计算通过具体后端模块调用。NumPy 后端服务数组正演，PyTorch 后端服务可微正演；物性关系由独立的关系模块表达。有限段正演和内部缺口附近的完整响应支撑由 `support` 模块计算，供井控质检和神经网络反演使用。
