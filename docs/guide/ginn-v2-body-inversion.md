# GINN V2 主体反演

主体反演使用地震、初始阻抗模型和几何信息，预测对数阻抗修正。时间域和深度域共用数据划分、网络、训练器、井监督、推理、体融合及波形报告；域适配负责米制垂向坐标和地震正演。

## 输出与低频背景

令初始对数阻抗为 $m_0$、网络修正为 $c$、25 m 高斯平滑为 $G$、上游低频模型采用的低通为 $L$：

$$
b_0=G(m_0),\qquad d=G(m_0+c)-b_0,\qquad m=b_0+d-L(d).
$$

零修正输出为平滑初模。网络修正主要作用于上游低通以外的尺度，低通的过渡带保留渐变。低频锚定以最终输出相对平滑初模的增量为对象，惩罚其剩余长波成分。初模提供低频背景，井和地震约束主体变化。

低通参数来自输入低频模型的制作记录：深度域使用米制截止波长，时间域使用赫兹。平滑半高全宽统一采用米。时间域将双程时间与冻结速度场积分为米制垂向坐标，速度体与完整初模网格同形，单位为米每秒；配置的输入段可用以下字段指定本地速度体：

```yaml
ginn_v2_body_inversion:
  inputs:
    velocity_volume: experiments/ginn_v2/inputs/velocity.npy
```

深度域默认通过冻结的阻抗—速度关系从初模生成速度。时间域也支持该关系；初模存在空值时，时间域使用覆盖完整采样轴的显式速度体。训练和推理读取同一份速度输入。时间正演要求冻结子波与地震时间步长一致；深度正演使用非平稳深度算子。

## 井监督与训练

已滤波原生井曲线先按各自时间或深度轴重采样到地震网格，再沿对应米制坐标进行一次 25 m 平滑，得到完整井目标。井目标的数值由井曲线确定；初模掩码限定共同建模范围。

| 损失 | 默认权重 |
|---|---:|
| 地震波形形状 | 1.0 |
| 井对数阻抗 | 1.0 |
| 井曲线垂向导数 | 0.5 |
| 井旁地震波形形状 | 0.25 |
| 相对平滑初模的低频锚定 | 1.0 |

形状项包含相关性和标准化波形误差。预训练使用地震与低频锚定，微调加入井监督。训练轮数、井名单和工区路径保存在本地实验配置，配置及产物位于仓库忽略的实验目录。

```powershell
python scripts/body_train.py --config experiments/ginn_v2/ginn_v2.yaml --output-dir experiments/ginn_v2/results/body_20261002
python scripts/body_infer.py --config experiments/ginn_v2/ginn_v2.yaml --checkpoint experiments/ginn_v2/results/body_20261002/selected_checkpoint.pt --output-dir experiments/ginn_v2/results/volume_20261002
```

当前权重格式记录低频受限的输出语义。历史权重对应其历史实现；本版训练生成的权重供当前推理入口使用。

## 体融合与报告

两个方向先融合完整的原始初模加修正曲线；边界位置按邻近修正补齐，再统一构造受低频限制的输出。直接道预测、训练和全体积输出使用同一构造。横向窗口按道索引寻址，距离由实际平面坐标计算，适用于横线号步长为 4 的工区。

输出包含线性阻抗体、相对原始初模的对数阻抗差、剖面和覆盖情况。该导出差包含初模自身平滑带来的变化；低频锚定和漂移统计采用平滑初模基准。井波形报告通过同一域适配正演，图件的纵轴和支持区间按采样域记录秒或米。时间域局部相关窗以冻结速度的局部中位米／秒比例换算窗口长度。
