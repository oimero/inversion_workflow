# 主体反演的基准对照配置

主工作流使用 ResCNN、物理预训练、遮挡与可见地震批次和可信井批次。主体平滑与低频投影共同定义预测输出。基准可以显式配置预训练、微调可见性、更新预算及可见地震的物理损失权重。

以下配置示例放在训练配置中，采用三轮微调、固定更新预算，并限制逐井误差：

```yaml
pretrain_epochs: 1
finetune_epochs: 3
finetune_strategy: mvw
finetune_unlabeled_steps: 64
finetune_well_steps: 64
visible_seismic_weight: 0.25
selection_well_rmse_tolerance: 0.0
```

每轮的无标签预算计算遮挡与可见批次的合计更新次数；混合方式将该预算交替分给两者。井预算单独计算。支持的方式如下：

| 配置值 | 微调批次 |
|---|---|
| `vw` | 可见地震与井批次 |
| `mw` | 遮挡地震与井批次 |
| `mvw` | 遮挡、可见地震与井批次；显式无标签预算在遮挡与可见之间交替分配 |
| `w_only` | 井批次，无标签预算为零 |

默认使用混合微调；未填写固定预算时，采用主工作流按数据批次数计算的调度。预训练轮数设为零时，微调从随机初始化开始。主体输出头采用主工作流的零修正初始化。仅井微调是机制对照条件。

可见地震的权重只作用于该批次的地震物理损失。井损失、遮挡地震损失及低频锚定使用各自原有权重。

启用逐井误差限值时，先确定汇总井误差最小的参考轮次，再保留每口井误差均不超过参考值乘以“一加容差”的候选轮次，选择其中可见地震相关性最高者。容差为零时，各井误差均不得劣于参考轮次。该规则比较已知井曲线，盲井指标由基准独立报告。

PostM 的地震支撑筛选使用原始逐道均方根振幅，相对于全剖面的中位振幅进行判断：

```yaml
seismic_support_relative_threshold: 0.25
```

筛选同时用于训练中心、邻道地震特征和预测中心；弱信号剖面的主体预测使用平滑初模。主工作流默认保留全部原有候选道。
