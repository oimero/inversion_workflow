# Enhance V3：GINN 主体引导的高频样本迁移

状态：待实现的框架草案。记录日期：2026-10-03。

## 目标与分工

GINN V2 提供受低频约束的主体阻抗，Enhance V3 根据主体的局部波形选择井样本，并将相应的高频细节迁移到目标位置。方法借鉴 SMI 波形差异反演的样本匹配思路；本文定义的是本项目自己的实现方案。

全流程在自然对数阻抗上计算，导出时取指数恢复线性阻抗。井位和井间使用同一套选样、变形和融合规则。井曲线用于建立码本和评价结果。

当前 GINN 主体的构造为：

$$
b_0=G(m_0),\qquad d=G(m_0+c)-b_0,\qquad b=b_0+d-L(d).
$$

其中，$G$ 是配置的主体高斯平滑，$L$ 是上游低频模型的低通。V3 读取最终主体 $b$；导出的“相对原始初模改变量”包含初模自身平滑的变化，与检索用的中频波形是不同对象。

## 输入与坐标

| 输入 | 用途 |
|---|---|
| GINN 最终线性阻抗体及其运行配置 | 提供固定主体、采样轴、有效区及主体处理规格 |
| 第六步井控结果中的已标定原生滤波井曲线 | 提供成对的主体结构与高频样本 |
| 解释层位与工区几何 | 定义层段、相对地层位置及真实横向距离 |
| 地震与已有正演输入 | 比较融合前后的波形变化 |

带采样轴的数据使用项目的 `SampleAxis` 及 `wtie.processing.grid.Log/LogSet/TimeDepthTable` 等对象组织。时间轴使用秒，频率使用 Hz；深度轴使用米，频带使用波数或米制波长。线号步长用于寻址，横向物理邻域使用 XY 坐标距离。

第一版采用解释层位之间的比例坐标：

$$
u=\frac{\xi-\xi_{\rm top}}{\xi_{\rm bottom}-\xi_{\rm top}},
$$

$\xi$ 为时间或深度。RGT 可作为后续显式配置的地层坐标来源。井曲线使用第六步的标定轴；该轴与层位轴的对应关系应作为输入契约写清。

## 主要流程

### 1. 构建成对码本

按层段和有限连续区间切取原生井曲线窗口。每个样本保存完整 log 阻抗、原生采样轴、层段与比例位置，以及由完整曲线得到的检索主体。窗口保留足够上下文，供变形、滤波和重叠拼接使用。

检索主体和高频细节必须来自同一个候选剖面。码本中的候选及其变形参数共同决定两者，保持粗细结构的对应关系。

### 2. 扩充完整候选

第一版以真实井窗为基础，采用受限的层厚伸缩、局部位置和阻抗对比度变化扩充候选。变形范围通过配置指定，参考井样本的实际变化幅度。

垂向变差函数模拟作为后续候选来源。它需要明确模拟对象、层段统计、扰动幅度和随机种子；候选仍应保留井样本的层序与细节结构。

一个重要限制是：若扰动只改变检索带外的高频，各候选的检索特征可能近乎相同。此时选样主要由先验和空间协调决定，增加候选数量本身不会提供更多地震信息。

### 3. 与 GINN 主体匹配

定义检索中频算子 $B$，与最终融合高频算子 $H$ 分别配置。首先将候选映射到目标道的实际时间／深度轴，再计算其检索特征；伸缩会改变实际频率，因此滤波和索引需要对应变形后的候选。

候选检索主体按 GINN 已有的主体尺度处理，然后使用 $B$ 提取中频波形；目标特征从 GINN 最终主体直接经 $B$ 提取。两侧的有效处理响应需要一致，GINN 最终体已经包含主体平滑。

第一版的匹配距离考虑中频波形形状、局部对比度和层段比例位置。形状归一化后，幅度信息仍单独参与匹配。每个位置保留少量近似候选，供空间协调选择。

### 4. 空间一致选样与拼接

在同层位置的邻域内协调候选选择，并检查垂向窗口的重叠一致性。第一版优先保留主要候选的完整细节结构，窗口交接通过有限重叠完成。

空间协调作用于选样和重叠关系。候选的细节随目标层位起伏移动，避免按相同绝对深度将井纹理横向铺开。明确的断层或层段边界限制邻域连接。

选中的完整候选经变形、重叠拼接，形成候选场 $q$。实现时按层段和空间块处理，使用候选检索索引与少量候选的精细比较，控制全体积内存与计算量。

### 5. 单次高频融合

在候选场完成变形和拼接后，执行：

$$
m_{\rm out}=b+\alpha H(q-b).
$$

$\alpha$ 为工区统一的替换强度。完整支持区内，$\alpha=1$ 时等价于保留 GINN 的互补低中频，换入候选的高频。目标区窗、有限区间边界及渐变窗应纳入最终滤波顺序，避免乘窗或拼接造成的长波变化进入融合增量。

高频交接范围依据实际频率响应配置。高斯半高全宽、滤波截止波长和可分辨层厚是不同量；主体平滑宽度不能直接充当交接波长。

## 与 Enhance V2 的关系

V2 已有井主体／残差码本、波形及导数等检索特征、受限伸缩变换和空间权重协调。V3 的主要变化是：

- 将完整井剖面的候选扩充纳入码本，使变形后的主体波形与高频结构共同参与选样。
- 显式定义与 GINN 输出相配的检索频带和处理响应。
- 沿地层组织空间一致选样，优先保留主要候选的细节。
- 在候选完成变形、拼接后统一做一次高频融合。

可复用 V2 的有限区间处理、几何取样及导出能力；核心匹配与融合语义按本规范组织。

当前 GINN 时间域主体仍使用冻结速度将时间换成米制坐标做平滑。候选主体处理复用该输入的实际规格；V3 自身的检索与融合频带按原生采样域定义。

## 后续实现顺序与输出

1. 实现真实井窗、比例地层坐标及受限结构变形。
2. 实现共同中频检索、主要候选选择与重叠拼接，先输出固定剖面。
3. 增加沿层空间协调及单次高频融合。
4. 支持分块全体积运行和 SEG-Y 导出。
5. 根据候选覆盖情况加入垂向变差模拟。

运行结果保存融合阻抗、实际注入的 log 阻抗增量、候选选择与有效区、剖面对比，以及融合前后的井阻抗误差和正演波形指标。留出井按普通目标道处理，其井曲线从码本及候选统计中排除；参与码本的井与留出井分别报告。

实施时仍需决定：窗口尺度与重叠、候选变形范围与数量、检索距离权重、检索频带、高频交接带、统一替换强度、横向邻域与协调强度。参数由实验配置明确提供，轴或单位冲突、候选不足等问题直接报错。
